# Lua 脚本候选

## 运行依赖与入口

CowType 使用 `fcitx5-lua` 的 `imeapi` 模块；Debian 系包名通常为 `fcitx5-module-lua`。扩展安装到 Fcitx 数据目录的 `lua/imeapi/extensions/cowtype.lua`。安装或升级扩展后重启 Fcitx5。设置的“脚本”页管理权限模式、脚本和示例；缺少模块或执行失败时显示提示并保留普通输入。

权限默认为关闭，脚本和示例均需逐项开启。示例添加按钮创建可编辑、默认停用的副本：“日期”使用 `riqi`，“时间”使用 `shijian`，均为非独立候选模式；“系统信息”使用 `xitong`，为独立候选模式，需要完全权限。脚本编辑显式保存，变更通知 CowType 重载，无需编译。编辑器使用可调整大小的模态子窗口，独立于父窗口边界，内容支持滚动。“脚本说明”可展开查看接口说明，“内容”下方使用可选 GtkSourceView 5 提供 Lua 高亮、行号和自动缩进；没有该库时使用普通 GTK 文本编辑器。

## 权限模式

| 模式 | 能力 |
|---|---|
| 关闭 | 不执行脚本 |
| 严格 | 每次调用创建独立环境，开放 assert、error、ipairs、pairs、next、select、tonumber、tostring、type，以及 math、string、table、utf8、os.date、os.time；不提供 io、require、package、debug、load、loadfile、dofile、os.execute、os.getenv 或 Fcitx API |
| 完全 | 通过全局环境开放 Lua/Fcitx 运行库，可执行任意命令、访问网络及读写用户可访问的文件；启用时需要确认权限提示 |

严格模式仅加载文本代码，不接受二进制字节码，不暴露调试接口和捕获错误接口。每次执行设置 100000 条 Lua VM 指令上限，失败时移除钩子并丢弃错误正文。它是 Lua 能力限制，不是独立进程或操作系统沙箱；没有独立内存配额，库函数的大额分配或耗时 C 调用不受 VM 指令计数约束。完全模式只适用于可信脚本，阻塞系统命令可能使输入法停止响应。其他 Fcitx Lua 扩展不受 CowType 模式设置控制。

## 脚本接口

全局 `input` 为完整匹配的触发字母，支持 1–64 个小写 ASCII 字母。每个脚本的“独立候选模式”默认关闭。

合并模式返回一个 `{number, string}` 或这种表的数组。优先级越小越靠前；普通候选按排序后的位置使用 1、2、3…，脚本在相同优先级时排在普通候选前。优先级可以为负数、小数或有限的科学计数值；同优先级脚本保持管理列表及返回顺序。例如 5 放在第 5 个普通候选之前，保留前 4 个普通候选，候选不足时追加到末尾。日期和时间示例使用 5、6：

```lua
return {{5, os.date('%Y-%m-%d')}, {6, os.date('%Y年%m月%d日')}}
```

```lua
return {{5, os.date('%H:%M')}, {6, os.date('%H:%M:%S')}}
```

开启“独立候选模式”后，脚本结果单独显示，Tab 在独立脚本列表与普通列表间切换。该模式支持相同的带优先级返回格式，也支持字符串或字符串数组，例如 `return os.date('%H:%M')`。同一触发词下的合并结果仍位于普通列表，独立结果位于单独列表。

保存合并脚本时，对主脚本的每个 return 分支静态检查显式的带优先级表，优先级要求十进制有限数字常量，文本表达式可调用函数；辅助函数内部的 return 不受该结构约束。直接返回字符串、字符串数组、变量表或无法静态确认的返回表达式会被拒绝，需使用显式返回表或开启独立模式。保存检查不执行 Lua，不执行任何命令，也不承诺验证完整 Lua 语法或动态文本类型。实际执行时再验证每项优先级和文本类型，拒绝 NaN、无穷大和无优先级的合并结果。

最多管理 128 个脚本，每个脚本不超过 64 KiB。每个脚本最多取 12 项；全部匹配脚本的结果按优先级稳定排序、在各自候选模式内去重，保留合计最多 12 项。每项必须是有效 UTF-8、无 NUL 的字符串，最多 4096 字节。选择脚本结果不产生学习记录。

完整触发词匹配时执行一次，并缓存结果至组合内容变化或重载；单纯重绘、翻页和光标移动不重复运行。合并结果使用核心会话的分页、光标、数字选择、标点上屏及翻译预览流程。独立模式支持数字键、上下键、空格、回车和鼠标选择，Tab 切换列表；Esc 取消组合。统一上屏路径处理简繁转换和可选自动加空格。开启脚本后，匹配已启用脚本的 `u` 前缀优先于自动 Unicode 码点输入。

脚本仅在普通中文组合中触发，英文、敏感输入框、独立码点及互译输入不运行。当前时间等动态信息以触发时刻为准。

## 内置示例的功能

| 脚本 | 触发词 | 候选模式 | 所需权限 | 返回内容 |
|---|---|---|---|---|
| 日期 | riqi | 合并 | 严格或完全 | 年月日的数字格式、中文格式，优先级 5、6 |
| 时间 | shijian | 合并 | 严格或完全 | 时分、时分秒，优先级 5、6 |
| 系统信息 | xitong | 独立 | 完全 | uname -s、-r、-m、-srm 的结果，共 4 项 |

日期与时间使用 `os.date` 获取本机当前时间，并通过格式符生成文本：`%Y` 为四位年份，`%m` 为月份，`%d` 为日期，`%H` 为 24 小时制小时，`%M` 为分钟，`%S` 为秒。两者返回带优先级的候选数组，默认插入普通候选列表，无需独立模式。

系统信息在脚本注释中声明完全权限需求，使用 `ipairs` 按固定顺序遍历 `-s`、`-r`、`-m`、`-srm` 四个参数，通过 `io.popen` 分别运行 `uname` 并读取标准输出第一行，关闭管道并检查命令是否成功。四项分别表示内核名称、内核发行版本、机器架构，以及三者的组合。命令和参数均为固定字符串，不拼接触发输入；执行失败时由 `assert` 中止，宿主显示通用失败提示。该脚本返回字符串数组，添加示例时自动选择独立候选模式；严格模式没有 `io`，无法运行此示例。添加示例不会自动开启脚本或提升全局权限。

## 文件与诊断

配置位于 `$XDG_CONFIG_HOME/cowtype`，默认 `~/.config/cowtype`。`settings-v2.ini` 的 `ScriptMode` 使用 `Off`、`Strict`、`Full`；`scripts/records.json` 使用版本 2 的记录格式，保存代码及每个脚本的 independent 选项，`scripts/index.tsv` 和随机名称的 `.lua` 文件是管理器生成的启用快照。不要单独编辑生成的索引或快照；使用设置页管理。

宿主以目录文件描述符逐级拒绝符号链接，只读取大小受限的普通文件。设置写入复用原子保存并拒绝含符号链接的路径。执行错误以“Lua 脚本执行失败：原因”显示，区分 imeapi 未加载、桥接数据异常、语法错误、指令超限、权限不足、未定义值、类型错误、断言失败及候选格式错误；能提取时显示脚本行号。提示给出对应排查方向，不包含脚本内容、触发输入、候选结果或原始执行错误正文。完全模式脚本自身可写入日志或其他文件，行为由脚本作者决定。

## 保存与启用检查

保存时检查合并候选的显式返回表，并对非独立脚本报告缺少 return、返回结构不正确、非有限数字常量优先级或表后附加表达式等方向，提供相关行号。此检查不执行代码，不是完整 Lua 语法验证；Lua 编译器在实际触发时检查语法。

保存和启用时均静态扫描严格模式未提供的全局接口，例如 io、require、package、debug、动态加载、os.execute、os.getenv 和其他受限模块。扫描忽略注释及字符串，报告接口名与行号；把 os 保存为别名或动态访问时也给出保守提示。静态推断可能因局部变量同名而误报，无法穷尽动态别名、构造字段或完全模式模块的全部行为，不代替运行时权限限制。

保存含受限接口的脚本时显示确认提示，可选择“仍保存”保留代码，不自动切换权限；已启用脚本若当前权限不足，仍保存会将其停用。启用时重新检查返回格式及受限接口；当前不是完全模式时保留停用状态并说明需要切换权限或修改代码，完全模式下需确认接口列表后启用。修改已启用脚本时也执行同样的检查。检查与保存过程不执行系统命令，不读取脚本结果。

## 配置迁移

主程序和设置程序检测到旧脚本配置时提示运行 `cowtype-config-migrate`，不在输入或设置主线自动兼容。设置的迁移提示提供运行按钮；该按钮请求重启 Fcitx5。

独立迁移器将原 scripts 目录完整移动到同级带时间戳的备份目录，生成新格式记录和索引，将已有脚本设置为独立候选模式，保留原代码和启停状态，不运行脚本。终端运行迁移器时，在结束前询问是否重启 Fcitx5，默认 Y。
