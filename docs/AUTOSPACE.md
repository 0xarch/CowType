# 中英文自动空格

“候选与模式”中的“中英文自动加空格”默认关闭。开启后，在汉字与 ASCII 英文字母、数字的相邻边界添加一个空格。例如连续输入 `Linux` 和 `输入法` 时得到 `Linux 输入法`；在汉字后以英文模式输入 `Linux` 时得到 `中文 Linux`。同次上屏正文中的中英数字边界也参与处理。

处理以当前应用提供的光标前字符为依据。应用必须提供有效 surrounding text，且输入框没有选区；不保留其他输入框或旧光标位置的内容。缺少可靠上下文时保持原样，不推测光标右侧内容，不补写尾随空格，不删除已有字符。已有空白、标点、Emoji 之间不添加空格。

密码、敏感、禁用输入法、网址、邮箱、数字、电话和终端输入框不参与处理。GB18030 与 Unicode 码点输入保留精确输出。语音和翻译在确认上屏时使用相同的边界处理；候选正文和个人学习记录不包含自动插入的空格。

`automatic-spacing` 原生测试在隔离 XDG 目录中使用合成输入框，检查字符分类、英文透传边界、中文候选上屏、设置重载、上下文缺失、选区、受限输入框及精确码点输出。实际应用是否提供 surrounding text 需要桌面人工验收。
