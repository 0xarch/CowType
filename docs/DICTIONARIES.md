# 拼音词库与匹配

## 权重和来源

重复键按规范化读音与文本合并，包括去音调、`ve/ue` 规范化产生的重合项。先相加原始权重，再计算 `log10(sum(weight))`；编译器使用稳定的 log-sum-exp，避免大权重溢出。跨来源重复项归入其中最高优先级来源。

“词库 → 系统词库 → 使用系统 Fcitx/libime 拼音词库”默认关闭；未设置该项的旧配置也按关闭处理，不改写用户配置。启用后合并本机 `/usr/share/libime/sc.dict`。它与“本地统计语言模型”相互独立。系统来源优先会改变排序并增加查询成本，不保证所有输入质量提高。

系统 `sc.dict` 的分数已是对数，按 `10^score` 换算后与文本词库合并；分数为 0 的词条贡献 1。雾凇和万象使用 manifest 转换后的原始 TSV 数值。

候选按完整消费、匹配类型、词库来源和 libime 词频/语言模型排序。完整精确读法和可靠简拼优先于纠错及补全；补充错拼候选保留在精确读法之后。多词组句按其最低优先级组成词归类。个人记忆不能让纠错读法越过精确读法。系统低频词仍可能排在仅由补充词库收录的高频词之前。

## 错拼纠正与补全

开启纠错后，原生适配器使用有界音节搜索补充漏键、重复键、相邻换位和 QWERTY 邻键候选。搜索以 libime 公开音节表和词典 trie 剪枝，共享输入偏移的转移结果，不建立第二份词典，也不为每种变形重新运行整句解码。搜索一次最多修复一个字母编辑，适用 3–32 个小写英文字母；显式分隔符不进入该补充分支。相邻换位还使用受限的精确音节枚举处理跨音节边界情况。

搜索状态、路径、词条访问和候选数均有上限；超出上限时接受当前召回结果，不保证高同音分支中的最高频词都能进入候选。完整、按实际字母可解释的读法保持优先。末尾音节补全在补全选项开启且没有完整字面读法时运行；正确完整输入不会为补全枚举增加额外候选。

0.4.3 在固定 1100 条合成集、系统 libime 1.1.17 上进行了同提交配对。默认雾凇、无模型的 Top-1 从 797/1100 提升至 847/1100，Top-5 从 937/1100 提升至 1035/1100，完整目标覆盖从 939/1100 提升至 1053/1100。错拼组覆盖从 149/200 提升至 199/200；补全组覆盖从 36/100 提升至 100/100。

独立固定的 200 条留出集上，完整覆盖从 160/200 提升至 191/200，错拼组从 60/80 提升至 80/80。留出集中有两条旧首选降至第 2 或第 3 位。固定样本是人工构造，包含共享词和模板，不代表自然用户输入分布，也不能保证其他输入没有排序变化。

## 个人记忆

仅在用户确认拼音候选时增加对应读音和文本的计数，不记录按键序列或未确认正文。候选排序分值为衰减计数减去一次确认的基线，因此权重 1 只保留记录，不单独改变顺序；再次确认后才形成可见偏好。每 30 天计数减半，个人记忆只在相同匹配类型中影响顺序，不能让纠错候选越过精确读法。设置可搜索、修改和删除记忆。

“本地统计语言模型”默认关闭。启用后加载本机 `/usr/lib/libime/zh_CN.lm`，不下载模型或读取 Fcitx 个人学习文件。模型用于 libime 解码和同来源候选排序；不可用时显示提示并保留基本输入。不同安装前缀可通过启动环境设置 `COWTYPE_SYSTEM_PINYIN_DICT` 和 `COWTYPE_STATISTICAL_MODEL_FILE`。

## 词库编译与缓存

采用 libime 公开的压缩二进制 trie 格式，三个来源层共用紧凑词条列。编译使用共享前缀 trie、连续权重和来源列，并流式读取文本以限制临时内存。该格式不是 mmap 零拷贝，加载仍需解压和内存分配。

构建时已有默认词库便生成雾凇缓存；若构建机有系统词库，再生成雾凇与系统组合缓存，安装到 `share/cowtype/dictionaries/compiled/`。运行时按源内容 SHA-256、编译格式和 libime 版本选择完全匹配的缓存。万象词库安装或源内容改变后，在后台编译到 `$XDG_CACHE_HOME/cowtype/dictionaries/`（默认 `~/.cache`）。模型开关共用词典缓存。

缓存具有长度界限和摘要校验，损坏或版本不符时重建；写入使用同目录临时文件和原子替换。缓存不可写时直接使用内存词库。缓存不包含用户输入或学习内容。可离线显式预编译：

```sh
cowtype-dictionary-compiler /path/to/ice/lexicon.tsv /path/to/wanxiang/lexicon.tsv /usr/share/libime/sc.dict /path/to/output
```

不使用某个来源时将对应参数传为空字符串。安装包不附带语言模型。

## 验证

`libime-dictionary-cache` 覆盖重复及跨来源权重、规范化、来源优先级、前缀消费、冷暖一致性、内容失效、缓存损坏和长度限制、不可写缓存及模型缺失。`libime-exact-before-correction` 检查精确读法、简拼、完整错拼排序、句子回补和复用工作区一致性。`libime-spelling-matches` 检查编辑操作、键盘邻接、音节边界、补全元数据和搜索边界。学习排序由 Rust Session 测试验证单次确认、重复确认和 native provider 的类型优先级。

Top-1、Top-5 和完整目标覆盖均使用固定参考答案；完整查询与逐前缀延迟分别统计，不能以候选非空率代替命中。合成样本存在相关性，成绩不应外推为自然输入总体准确率。更多构建和测试命令见[构建说明](BUILD.md)。

## 自定义词库

设置 → 词库 → 自定义词库支持添加、编辑和删除触发字母、内容及权重，改动自动保存到 `$XDG_DATA_HOME/cowtype/custom-v1.tsv`（默认 `~/.local/share/cowtype/custom-v1.tsv`），文件权限为 0600。单次编辑通过原子替换和并发冲突检查。

最多 10,000 条、文件最大 8 MiB。触发字母为 1–64 个英文字母，保存时转成小写并完整匹配；同一触发字母可对应多项内容。内容最多 4096 个字符，可包含换行和制表符。权重为 1–1,000,000 的整数，默认 100；同一触发项按权重降序，同权重保持添加顺序。

自定义词条优先于普通词和 Emoji，不参加个人学习，也不与系统词库原始频率相加；拼音和五笔均可用。自定义索引在后台更新，无需手动编译；以 `u` 开头的已定义触发前缀优先于隐式 Unicode 输入，独立 Unicode 模式不受影响。损坏文件会保留最后有效索引并显示固定错误提示。
