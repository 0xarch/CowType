# 拼音词库权重与预编译

## 权重和来源

重复键为规范化读音与文本的组合，包括去音调、`ve/ue` 规范化之后产生的重合项。先合并原始权重，再计算 `log10(sum(weight))`；为 libime 提供的词典分数减去全部有效贡献权重的对数。编译器使用稳定的 log-sum-exp，避免直接累计极大权重溢出。跨来源重复项也合并，并归入其中最高优先级的来源。

“词库 → 系统词库 → 使用系统 Fcitx/libime 拼音词库”默认关闭；未配置此项的旧设置也按关闭处理，不改写用户配置。启用后合并本机 `/usr/share/libime/sc.dict`，关闭后只使用雾凇和用户选择的万象。它与“本地统计语言模型”相互独立，关闭系统词库仍可开启模型。系统来源优先会改变排序并增加查询成本，不保证所有输入质量提高。

系统 `/usr/share/libime/sc.dict` 的分数已经是对数，按 `10^score` 解释后与文本词库合并；系统文件分数为 0 的词条贡献 1，不虚构额外语料次数。雾凇和万象使用 manifest 转换后的原始 TSV 数值。

候选先按是否消费完整输入分组；完整组内保留字面读音和非纠错简拼的优先级，完整纠错结果位于只匹配前缀的候选之前。每组内部区分纠错、精确读音及系统 Fcitx/libime、万象、雾凇来源；同类同来源的完整字面候选以无纠错搜索的顺序为准，其余保留 libime 频率或语言模型顺序。多词组句归入其最低优先级组成词的来源。用户显式短语和已有个人学习遵循会话层规则。严格来源优先并不保证所有同音词都符合个人预期，例如系统中的低频词仍可排在仅补充词库收录的高频词之前。

原生适配器以一次启用所需纠错选项的解码为主，并依据 libime 公开的 lattice 节点标记识别纠错；最佳路径含纠错节点或由多个词组成时，额外查询无纠错图并回补完整字面读音，避免纠错搜索剪枝或不同分词挤掉正确句子。它保留两份有界纯查询工作区，分别服务有/无纠错图：连续查询的选项相同时，追加和尾部退格复用图状态，不相关输入或选项变化重建；有/无纠错模式切换会清空关联图，回补路径不承诺跨模式增量复用；工作区不选词、不学习、不设置上文，输入框的组合和选择状态由各自会话维护。读音与来源信息在单次查询中提取和复用，不在每次排序比较时重复查询词典。共享解码器仍在锁内串行访问；图状态仅为可丢弃的加速数据，不是个人历史。

### 有界错拼补充

开启纠错且原生列表没有可靠的完整多音节字典词时，4–24 个小写英文字母的输入可使用独立的完整词补充路径。它枚举重复键删除及相邻字母换位，利用 libime 的公开音节表和词典 trie 剪枝，只查完整词，不为每个变体重跑整句解码；不跨显式隔音符修复，也不扩展任意字母插入或替换。

单次上限为 32 个变体、1024 个搜索状态、32 条完整音节路径、最多处理 128 个词条及 16 个补充结果，音节数限 2–6。到达词条预算后，其他来源层可执行退出检查；这不是严格 128 次回调上限。先截断后按词典权重排序，因此高同音分支不保证最高频词全部进入预算。新增结果按纠错候选合并并去重，不删除原生候选；完整非纠错词和真实简拼保留优先级。该策略主要提高错拼目标进入首屏的机会，不保证取代所有已有首选。

固定 1100 条合成集、系统 libime 1.1.17 的同轮配对中，默认雾凇无模型的错拼完整覆盖和前五项命中均由 86/200 提高到 149/200，整体前五项由 874/1100 提高到 937/1100，首选保持 797/1100。全串查询 p50 为 0.461→0.470 ms，前缀 p50 为 0.592→0.625 ms；前缀 p95 有约 5% 的增加。新增目标多数位于第二项，这不是任意错拼首选纠正的保证。模型独立开启也可使用该补充；合成模板与变形相关性、词库和库版本限制均需保留，不能将此结果外推为真实输入总体准确率。

“本地统计语言模型”默认关闭。在设置的拼音分组手动开启后，只加载本机 `/usr/lib/libime/zh_CN.lm`，不下载模型，也不读取 Fcitx 的个人学习文件。模型用于 libime 解码和同来源候选排序；不会越过上述来源层级。模型不可用时显示提示并保留基本输入。安装不同前缀的发行版可在启动环境中指定 `COWTYPE_SYSTEM_PINYIN_DICT` 与 `COWTYPE_STATISTICAL_MODEL_FILE`；显式空系统词库路径可禁用系统层。

## 编译与缓存

采用 libime 公开的压缩二进制 trie 格式，三个来源层互不重复。编译时用共享前缀 trie 映射紧凑词条 ID，以及连续的权重、来源列；流式读取文本，避免同时保留全部解析行和 Rust 冗余索引。不是 mmap 零拷贝方案，加载仍需要解压和内存分配。

构建时已有默认词库便生成雾凇缓存；若构建机有系统词库，再生成雾凇与系统组合缓存，安装到 `share/cowtype/dictionaries/compiled/`。运行时以源文件内容 SHA-256、编译算法格式及 libime 版本选择完全匹配的缓存。万象安装或源内容改变后，在后台重新编译到 `$XDG_CACHE_HOME/cowtype/dictionaries/`（未设置时使用 `~/.cache`）。模型开关共用词典缓存。

缓存每层有长度界限和摘要校验，损坏或版本不符会重建；使用同目录临时文件与原子替换。缓存不可写时直接使用内存词库。未持久化用户输入或学习内容。可在不联网的情况下显式预编译：

```sh
cowtype-dictionary-compiler /path/to/ice/lexicon.tsv /path/to/wanxiang/lexicon.tsv /usr/share/libime/sc.dict /path/to/output
```

不使用可选来源时将相应参数传为空字符串。安装包不附带语言模型。

## 验证与测量

`libime-dictionary-cache` 原生测试覆盖重复和跨来源权重、规范化重合、来源优先级、前缀消费、冷暖一致性、内容失效、损坏及超长截断缓存、可选词库拒绝、缓存不可写和模型缺失。`libime-exact-before-correction` 检查字面和简拼保护、完整纠错排序、纠错剪枝下的字面句回补，并逐项比较追加、退格、替换、输入框交错、非法输入及功能开关变化时的复用工作区与全新解码器结果。

查询性能分别统计完整输入和逐字符前缀的延迟分位数；Top-1、Top-5 和完整目标覆盖使用固定合成参考答案，不能用非空候选率代替。对照实验记录源码提交、工作树头文件摘要、公开数据摘要及模型开关；结果不含 GUI、个人学习或语音进程。追加和退格的工作区复用还须通过与全新解码器逐项等价的检查。

开发构建提供 `cowtype-dictionary-benchmark`，参数与编译器相同，末尾再传模型 `0` 或 `1`；缓存目录放在第四参数。显式传公开数据路径，不读取个人配置。分别用新目录和已有目录运行，可测首次编译与缓存加载；输出加载耗时、进程自身峰值 RSS 和固定公开测试输入的候选数量，不输出正文。

本机 Release/libime 1.1.17 的固定 1100 条合成集配对查询中，系统加雾凇、模型关闭的完整查询 p50 为修正前 1.470 ms、修正后 1.306 ms；逐前缀 p50 为 2.016 ms、1.640 ms；Top-1 为 727/1100、788/1100，完整目标覆盖均为 868/1100。开启统计模型时完整查询 p50 为 3.763 ms、2.952 ms，p95 为 24.553 ms、24.775 ms。纯雾凇前缀 p95 也有小幅上升，不能据中位数宣称所有尾延迟改善。合成集含共享词语变形和句子模板，不代表自然输入总体准确率；这些是原生 API 时间，不含完整桌面、个人学习或语音。

设计参考 [WowType PR 283](https://github.com/Gloridust/WowType/pull/283) 的紧凑列、预编译和降低临时峰值思路；未复制其实现或快照格式。来源和许可见 [SOURCES.json](SOURCES.json)。

## 自定义词库

设置 → 词库 → 自定义词库 → 编辑自定义词库，可添加、修改和删除“触发字母、内容、权重”。有效编辑自动保存到 `$XDG_DATA_HOME/cowtype/custom-v1.tsv`（默认 `~/.local/share/cowtype/custom-v1.tsv`），文件权限为 0600；每次编辑使用原子替换及并发冲突检查。最多 10,000 条、文件最大 8 MiB。

触发字母为 1–64 个英文字母，保存时统一小写，完整匹配；不同内容可使用相同触发字母。内容最多 4096 个字符，支持换行和制表符。权重为 1–1,000,000 的整数，默认 100，常用可设 100–1,000。同一触发字母下按权重降序，同权重保持添加顺序。自定义词条优先于普通词和 Emoji 候选，不参加个人学习，也不与系统词库的原始频率相加；拼音和五笔均可使用。显式词条中的 Emoji 按保存内容直接上屏。以 `u` 开头的已定义触发字母前缀优先于隐式 Unicode 码表入口；独立 Unicode 模式不受影响。

无需手动编译：后台在文件变化后建立独立内存索引，后续输入仅查索引，不逐行扫描文件；约半秒内同步，下一次输入或修改组合时使用新词条。更新不重载默认/万象词库，不中断语音或翻译。文件损坏时保留最后一次有效词库并提供固定错误提示，不输出自定义内容。

本机 Release 构建的合成 10,000 条词库约 272 KiB，解析和建立索引约 10.4 ms，完整查询均值约 0.083 µs（100,000 次，仅测自定义索引，不含主解码器和界面）。持久化预编译只能省去文件变化时这一次解析，对每次按键没有额外收益，因此未增加编译按钮。复测：`cargo test --release --test custom_dictionary indexed_personal_dictionary_benchmark -- --ignored --nocapture`。结果受硬件和词条长度影响，非完整桌面性能验收。
