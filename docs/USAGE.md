# 使用与当前能力

安装本地构建的 Arch 实验包后重启 Fcitx5，在 fcitx5-configtool 添加“牛打字·拼音”或“牛打字·五笔86”。运行 cowtype-config 打开设置。程序不会自动更改桌面输入法配置。

## 文字输入

数字键选择候选，PageUp/PageDown 翻页；方括号与减号/等号翻页可在按键页分别关闭。F6 或启用的 Shift 单按切换中英文。候选数量、横竖排、拼音注释、中文标点、简拼、组句、纠错和学习可配置。拼音使用系统 libime 与随包 TSV 词典，不加载系统 libime 语言模型。五笔使用公开五笔86文本码表。

默认词典为固定版本的雾凇显式注音表和 rime-wubi。可选万象文本词典只在用户操作后下载并启用，不下载语法模型。各原始表、许可与转换摘要保留在生成数据内；精确输入见 src-data-tools/manifest/sources.json。词典缺失或后台加载时保留原输入，加载失败提供错误提示。

## 设置与语音

设置有输入、按键、语音、互译、词库五页，偏好即时保存，并通知 Fcitx5 重载。互译目前未实现。语音默认关闭，需要用户准备兼容的双图 Paraformer ONNX 模型及系统 ONNX Runtime；麦克风通过 parecord 使用 PulseAudio/PipeWire-Pulse。模型准备会联网、安装隔离环境依赖并导出，请先阅读 [准备工具](../src-voice/paraformer/README.md)。

语音键可选功能键或修饰键。修饰键短按切换开始/结束；启用长按录音时，按住 300 ms 开始，释放结束。组合键、失焦或取消会停止当前会话；录音结果不应上屏到其他输入框。系统是否传递 Alt/AltGr 等事件取决于桌面和 Fcitx5 前端。

可保留或预热语音实例以减少重复加载；预热不打开麦克风、不下载模型。关闭保留实例可释放模型内存。录音显示固定宽度音量条。模型不随包分发，选择/下载资源不能保证任意模型可运行。文字模型下载工具尚未接入候选重排。

## 日志与限制

引擎诊断在 `$XDG_STATE_HOME/cowtype/engine.log`，默认 `~/.local/state/cowtype/engine.log`，记录加载阶段与耗时，不记录按键、候选、词条、音频或识别正文。日志写入失败不能阻断输入。

首次校验词典和建立 libime 索引仍需要时间和内存；相同资源重载可复用引擎。可选大词库会增加内存占用。目前只提供 Arch x86_64 实验包，完整 Wayland/X11 应用、修饰键事件顺序、实际设备和系统安装/卸载仍需在目标环境验证。翻译、GNOME 扩展、文字模型重排与其它高级功能未完成，不把设置占位或下载脚本当成可用运行功能。
