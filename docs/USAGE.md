# 使用与当前能力

安装本地构建的 Arch 实验包后重启 Fcitx5，在 fcitx5-configtool 添加“CowType·拼音”或“CowType·五笔86”。运行 cowtype-config 打开设置。

## 文字输入

数字键选择候选，PageUp/PageDown 翻页；方括号与减号/等号翻页可在按键页分别关闭。
F6 或启用的 Shift 单按切换中英文。候选数量、横竖排、拼音注释、中文标点、简拼、组句、纠错和学习可配置。
拼音使用系统 libime 与随包 TSV 词典。
五笔使用公开五笔86文本码表。

单按 Shift 切换中英文启用时，可开启“状态保留”，在切换回 CowType 时保留当前输入框的中英文状态。
默认关闭，每次切换回 CowType 都使用中文；关闭单按 Shift 切换时，状态保留不生效。
状态仅保存在当前 Fcitx5 进程的输入框会话中。

默认词典为固定版本的雾凇显式注音表和 rime-wubi。
可选万象文本词典只在用户操作后下载并启用，不下载语法模型。
各原始表、许可与转换摘要保留在生成数据内；精确输入见 `src-data-tools/manifest/sources.json`。
词典缺失或后台加载时保留原输入，加载失败提供错误提示。

## 设置与语音

在 Fcitx5 设置工具中打开 CowType 拼音或五笔的配置，可通过“打开 CowType 设置”按钮启动设置程序。

设置有输入、按键、语音、互译、词库五页，偏好即时保存，并通知 Fcitx5 重载。
语音默认关闭，需要用户准备兼容的双图 Paraformer ONNX 模型及系统 ONNX Runtime；麦克风通过 parecord 使用 PulseAudio/PipeWire-Pulse。模型准备会联网、安装隔离环境依赖并导出，请先阅读 [准备工具](../src-voice/paraformer/README.md)。
互译目前未实现。

语音键可选功能键或修饰键。修饰键短按切换开始/结束；启用长按录音时，按住 300 ms 开始，释放结束。组合键、失焦或取消会停止当前会话；录音结果不应上屏到其他输入框。系统是否传递 Alt/AltGr 等事件取决于桌面和 Fcitx5 前端。

可保留或预热语音实例以减少重复加载；预热不打开麦克风、不下载模型。关闭保留实例可释放模型内存。录音显示固定宽度音量条。模型不随包分发，选择/下载资源不能保证任意模型可运行。文字模型下载工具尚未接入候选重排。

## 日志与限制

引擎诊断在 `$XDG_STATE_HOME/cowtype/engine.log`，默认 `~/.local/state/cowtype/engine.log`，记录加载阶段与耗时，不记录按键、候选、词条、音频或识别正文。日志写入失败不能阻断输入。

首次校验词典和建立 libime 索引仍需要时间和内存；相同资源重载可复用引擎。
可选大词库会增加内存占用。

拼音来源顺序、可选本地统计模型与预编译缓存见[词库说明](DICTIONARIES.md)。统计模型默认关闭，在输入页的拼音分组手动开启。

## 表情与符号

在 CowType 设置的“输入”页开启“表情与符号候选”（默认关闭）。输入中文关键词的拼音，例如 `xiaolian` → 笑脸/😀、`weixiao` → 微笑/😊；五笔也可通过完整中文候选匹配。英文可直接输入 `grinningface` → 😀、`thumbsup` → 👍、`copyright` → ©️。多词英文名称连写，匹配时忽略 ASCII 空白和标点。

使用 Unicode CLDR 中英文名称与关键词进行完整匹配，不做前缀或纠错扩展。保留原文字词，最多补充 12 个表情/符号家族候选，同一表情的肤色变体只占一项；选中后的肤色确认见下文。支持完整组合表情及肤色序列。开关即时作用于当前输入，关闭时移除补充候选。数据随程序提供，全程离线，无需下载模型或字体；显示效果取决于系统字体对对应 Unicode 版本的支持。

## GB18030 内码和快捷键

默认 F7 进入 GB18030-2022 内码输入：输入 `d6d0` 得到“中”、`9439fc36` 得到 😀。输入 3/7 位十六进制会列出前缀候选，继续输入到 4/8 位可精确定位；使用上下键选择，空格/回车或鼠标提交，Esc 或再次按快捷键退出。进入时普通拼音/五笔组合暂存，退出后恢复。失焦会清理内码输入，敏感输入框不启用。

在设置的“按键”页统一分配中英文、GB18030、Unicode、语音和翻译快捷键；各功能都可选择 F1–F12、Shift/Ctrl/Alt/Super 的左右侧或任一侧、AltGr、禁用。任一侧修饰键与其左/右侧绑定重叠时也会提示冲突并拒绝保存。修饰键单按释放触发，参与组合键时不触发。语音保留长按设置，关闭语音时也保留其绑定。它们仅在 CowType 内生效，不是桌面全局热键。

中英文现在仅使用所选快捷键，选择 F6 后 Shift 不额外切换。旧配置若缺少 ModeHotkey 且原先开启 ShiftToggle，会迁移为设置中可见的 Shift 绑定。状态保留适用于任意中英文绑定。

内码转换需要系统提供 2022 版 GB18030 映射；旧系统会提示不支持。可升级系统运行库后重试。实现与许可说明见[内码组件](../src-fcitx5/gb18030/README.md)。

## Unicode 码点输入

Unicode 和 GB18030 是独立模块，分别配置快捷键。默认 F9 开启 Unicode，F7 开启 GB18030；输入 `4E2D` → 中、`U+1F600` → 😀、`20000` → 𠀀。Unicode 不依赖系统 GB18030 转换器。使用空格/回车或鼠标提交，Backspace 编辑，Esc 或再次按快捷键退出，普通拼音/五笔组合会恢复。

两种码表的操作提示在开始输入后隐藏，删空后恢复。设置“输入”页另有默认开启的“u 前缀 Unicode 输入”：中文模式下直接在新组合开头输入 `u0020` → 空格、`u4e2d` → 中、`u1f600` → 😀，用空格/回车或鼠标提交。单独 u 保留普通候选，后续十六进制字符不再用于数字选词。退格删回 u 时恢复普通输入，Esc 取消；英文模式不触发。该开关和独立 Unicode 快捷键互不依赖，关闭其中一个仍可使用另一个。

Unicode 最多输入 6 位十六进制，支持可选 `U+` 前缀，拒绝越界码点、代理项和 C0/C1 控制字符。两种码表可用各自快捷键直接切换，未提交的码表输入会清理。各功能共用同样的快捷键选项，详见[Unicode 模块说明](../src-fcitx5/unicode/README.md)。旧配置若已占用 F9，新 Unicode 绑定默认禁用，需自行分配。

## API 互译

在设置“互译”页启用，默认关闭。可选免 Key 的 Bilibili Index-Translate，或填写自定义 OpenAI 兼容 API 地址和模型。默认自动中英互译，也可固定译成中文、英语、日语、韩语、法语、德语等常用语言，源语言由模型判断。修改服务后点击“保存翻译配置”；Bilibili 模型与自定义地址、模型和 Key 来源分别保存，切换服务不会互相覆盖。

默认 F10 翻译当前拼音/五笔候选；没有组合和选区时进入翻译输入模式。应用选区翻译暂缓支持，有选区时会给出提示，不发送选区正文。该模式中拼音/五笔选词暂存而不上屏，Enter 发送；先切到英文模式再进入可直接输入英文和空格。结果作为候选显示，1/空格/回车或鼠标确认后提交，Esc 或再次按 F10 取消。失焦、切换功能或重载配置会取消请求。旧配置已占用 F10 时，新翻译绑定默认为禁用。

自定义 Key 可选读取 `COWTYPE_TRANSLATE_KEY` 环境变量（优先当前进程，设置窗口未继承时读取当前用户 Fcitx5 的同名环境变量），或在密码输入框填写并保存到桌面 Secret Service 密钥环。普通配置文件不保存 Key；密钥环不可用时会报错，需解锁/安装 Secret Service 或改选环境变量。API 地址与模型只在设置内配置，运行时不会从 `COWTYPE_TRANSLATE_API`、`COWTYPE_TRANSLATE_MODEL` 读取。

翻译会将主动选择的输入候选或翻译输入模式中的文本发送到所选服务；基本拼音、五笔和本地语音不依赖它。只有主动发送或点击“测试接口”才会联网，不保存翻译历史或日志正文，不自动更换服务。支持范围、输入限制和密钥环依赖见[互译组件说明](../src-translate/README.md)。

## 表情与肤色

启用“表情与符号候选”后，“右”或“右箭头”可匹配 →。普通候选中，同一表情的不同肤色合并成一项，不分别占用候选名额。默认开启“多肤色选择”：选中表情后，用数字键、空格、回车或鼠标确认肤色，必要时翻页；Esc 或退格返回上一级，输入仍保留。关闭此开关则直接使用默认肤色，默认肤色通过 👍👍🏻👍🏼👍🏽👍🏾👍🏿 单选组设置。
