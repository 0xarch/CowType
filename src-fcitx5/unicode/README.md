# Unicode 码点输入

独立于 GB18030 的直接 Unicode 标量转换模块，使用原创的 UTF-8 编码算法，不调用 iconv、不依赖 GB18030 模块，也不加载外部码表或模型。默认 F9 启用；GB18030 保留自己的 F7，两项快捷键都可在设置“按键”页独立修改或禁用。

输入 1–6 位十六进制，可选 `U+`/`u+` 或 `u`/`U` 前缀，例如：

- `4E2D` 或 `U+4E2D` → 中
- `1F600` 或 `U+1F600` → 😀
- `20000` → 𠀀

每个有效的当前码点产生一个候选，可继续输入到所需位数；空格/回车或鼠标提交。不会自动提交早期前缀，例如输入 `1F600` 过程中出现的较短码点。Backspace 编辑，Esc 或再次按该快捷键退出。支持大写和数字小键盘。

操作提示仅在独立模式的缓冲为空时显示；开始输入后隐藏，删空后恢复。

## 普通输入中的 u 前缀

设置“输入”页的“u 前缀 Unicode 输入”（`UnicodePrefix=True`）默认开启。中文模式下，在一段新组合开头输入 `u0020` → 空格、`u4e2d` → 中、`u1f600` → 😀，也支持大写 `U` 和 `u+`。后续十六进制数字作为码点输入，不用于数字选词；空格/回车或鼠标提交，Esc 取消。其他组合中的 u 以及英文模式不触发。

单独输入 `u` 时保留普通候选（包括开启表情匹配时的候选），继续输入十六进制字符或 `+` 才进入码点匹配。退格删到只剩 u 时恢复普通组合；纯字母序列遇到非十六进制字母时也恢复普通输入，例如 `ubuntu`。已含数字或 `+` 的码点序列按独立模式的输入规则处理，无效码点可退格修改或 Esc 取消。

该开关与 `UnicodeHotkey` 完全独立：禁用独立快捷键不影响 u 前缀，关闭 u 前缀也不影响快捷键进入的 Unicode 模式。两者共用标量校验、UTF-8 编码和候选渲染；自动前缀消费原来的 u，提交后不会恢复多余的 u。两种入口都不依赖 GB18030。

拒绝超过 U+10FFFF、代理项 U+D800–DFFF 以及 C0/C1 控制字符（含 NUL）。允许空格、格式字符、组合字符、私用区和非字符等其他 Unicode 标量；某些字符可能不可见或没有字体字形，最终显示由应用和系统字体决定。不对输入提供 Unicode 名称或类别查询，不捆绑 Unicode 数据文件。

普通拼音/五笔的组合在进入时暂存，退出或提交后恢复。直接切换到 GB18030 时丢弃未提交的 Unicode 缓冲，反向切换亦然；两者拥有独立状态。失焦、输入法切换、重置、配置重载或敏感输入框会清理该模式，码点内容不进入日志或学习记录。

Unicode 使用统一快捷键注册表中的 `UnicodeHotkey`。如果旧配置已经把 F9 分配给语音、中英文或 GB18030，且没有显式配置 UnicodeHotkey，升级时只将新的 Unicode 绑定设为禁用，不改写既有绑定。显式分配的重复或左右修饰键重叠仍按统一规则拒绝。
