# GB18030-2022 内码输入

CowType 的独立 C++ 内码转换和模式适配，使用系统 iconv。交互设计参考 openKylin 的 [fcitx5-gb18030](https://github.com/openkylin/fcitx5-gb18030)，本地审阅提交 `e9d69af71876d832da4929ebe98b019705123454`。没有复制上游候选窗口、引擎或转换代码；具体署名与许可核实见 [NOTICE](NOTICE.md)。

默认 F7 进入，输入 4 位双字节或 8 位四字节十六进制；例如 `d6d0` → 中，`9439fc36` → 😀。输入 3/7 位时枚举最后一个十六进制位的有效候选，继续输入可补全内码。上下键选择候选，空格/回车或鼠标提交，Backspace 编辑，Esc 或再次按快捷键退出。数字/a–f 始终用于输入内码，不用于按序选词；支持大写和数字小键盘。

进入时保留普通拼音/五笔的当前组合；退出或提交内码后恢复。输入框失焦、切换输入法、重置、配置重载或敏感输入框会清理内码模式，输入内容不写入日志、词库和学习记录。每次转换独立创建并关闭 iconv 句柄，检查完整消费、字节结构及单个 Unicode 字符，拒绝无效或未分配码。

系统必须提供更新到 GB18030-2022 的映射。首次启用会检查 18 个 2022 年变更的双字节映射及 2005 年的 `a8bc` 映射；旧实现返回私用区字符时拒绝进入并给出提示，不偷偷切换转换器。此检查不是全标准一致性认证；转换结果最终依赖系统 libc 的 GB18030 表。未捆绑标准文本或额外字符映射大表。

## 快捷键注册

`src/config/shortcuts.tsv` 统一登记 CowType 功能的默认键和可选值，Rust 配置解析及 GTK 设置共同读取；原生派发集中在 `engine/shortcuts.h`，ABI 选项 13/14 提供中英文与内码键编号。F6 默认为切换中英文，F7 默认为内码，F8 默认为语音。中英文和内码支持 F1–F12 或禁用，语音保留既有修饰键及长按行为。包括暂时关闭的功能在内，配置均禁止相同快捷键分配，保证后续开启功能时不会产生隐藏冲突。未配置这些字段的旧配置继续使用默认值。

统一管理范围为 CowType 激活时的功能快捷键，不注册系统桌面的全局热键；外部程序及 Fcitx5 自己的快捷键冲突仍由用户配置。普通编辑/选词键按当前模式处理。单按 Shift 的中英文切换继续由独立开关控制，在内码模式中不触发；组合键传给应用。新增功能应先注册，再增加唯一派发动作和冲突测试。
