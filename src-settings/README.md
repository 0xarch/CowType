# 设置界面

Python GTK4/libadwaita 设置，包含输入、按键、语音、互译和词库五页。运行 `python3 src-settings/app/main.py --page input`，安装后使用 cowtype-config。语音和可选词典只在用户操作后下载；互译页配置 Bilibili 或自定义 OpenAI 兼容服务、目标语言及环境变量/密钥环 Key，显式保存服务设置或测试接口。详见 [USAGE](../docs/USAGE.md) 和[互译组件](../src-translate/README.md)。

启用“表情与符号候选”后显示肤色设置：可开关选中表情后的二级肤色选择，并通过 👍👍🏻👍🏼👍🏽👍🏾👍🏿 六个互斥单选按钮选择默认肤色；开关关闭后仍可配置默认肤色。

输入页依次为候选与模式、拼音、表情与符号、学习与隐私、系统集成。“表情与符号”集中提供候选开关、优先匹配 Emoji、多肤色选择和默认肤色；主开关保持可见，其他选项仅启用候选后显示。优先匹配 Emoji 默认关闭，即优先普通符号。

“学习与隐私”提供“查看与修改记忆”：分页搜索个人学习记录，查看权重、保存值及时间，并支持修改和删除。`app/memory.py` 负责界面，`config/memory.py` 只读取快照并排队编辑请求；实际文件由 Rust 学习服务或显式辅助命令原子保存，避免覆盖并发学习。

词库页新增“自定义词库”：字母触发、内容和权重自动保存，可搜索、分页、编辑和删除，编辑页说明权重范围和排序规则。`app/custom.py` 提供界面，`config/custom.py` 提供私有文件校验、原子保存和编辑冲突检查。
